# 账单凭证数量限制

## 规则

- 每笔账单累计最多保留9张凭证，包含不同上传批次。
- 单张大小仍不能超过5MB，原有图片格式校验保持不变。
- 上传接口仍为`POST /api/v1/transactions/{id}/images/`，每次接收一个`image`文件。
- 第9张允许上传，第10张返回HTTP 400及统一错误结构。
- 删除一张后可再上传一张。
- 历史已超过9张的账单保留原文件及记录，达到9张或更多时禁止新增。
- 不修改账单金额、账户余额、资产快照及原有接口返回结构。

超限提示：`每笔账单最多上传9张凭证，请删除已有凭证后再上传`。

## 后端实现

在保存图片文件前执行数量校验。上传和删除使用同一账单行锁，
图片ID也采用锁定读取，在MySQL事务中按账单串行处理，避免并发请求超限。
数量限制属于业务规则，没有模型变更，不需要新增迁移。
SQLite检查验证边界及回归，不代替实际MySQL并发锁测试。

## 前端实现

适配`bookkeeping_vue`中的凭证上传和凭证列表组件：

- 已上传数量加待上传数量最多为9张，多选超出部分不加入队列并给出提示。
- 显示已上传、待上传、剩余可选择数量，达到上限时禁用选择入口。
- 删除已有图片或移除待上传图片后释放名额。
- 每轮上传前读取服务器已有数量，兼容创建账单后重试及多页面上传。
- 读取数量失败时不上传，保留队列供重试；后端始终执行最终数量校验。
