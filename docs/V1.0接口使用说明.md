# V1.0接口使用说明

本文记录个人记账V1.0核心接口的实际地址、注册登录规则及金额筛选参数，供前端联调和Apifox验证。预算、周期账单等扩展接口见《API补充功能说明》。

## 公共配置

本地服务地址示例：`http://127.0.0.1:8000`。所有接口必须包含`/api/v1/`前缀和末尾斜杠。

登录、注册无需Token；其他业务接口请求头使用`Authorization: Bearer <access_token>`。JSON请求体使用`Content-Type: application/json`。

统一JSON响应：`{"code":200,"message":"success","data":{}}`。文件导出成功时直接返回CSV；实际消息以各接口返回为准。

## 核心接口地址

| 方法 | 地址 | 用途 |
|---|---|---|
| POST | `/api/v1/auth/register/` | 注册 |
| POST | `/api/v1/auth/login/` | 用户名或邮箱登录 |
| POST | `/api/v1/auth/refresh/` | 刷新Token |
| POST | `/api/v1/auth/logout/` | 退出登录 |
| GET / PUT | `/api/v1/users/me/` | 查询、修改个人资料 |
| PUT | `/api/v1/users/password/` | 修改密码 |
| POST | `/api/v1/users/avatar/` | 上传头像 |
| GET / POST | `/api/v1/accounts/` | 账户列表、新增账户 |
| GET / PUT / DELETE | `/api/v1/accounts/{id}/` | 账户详情、修改、逻辑删除 |
| GET / POST | `/api/v1/accounts/transfers/` | 转账记录、创建转账 |
| GET / DELETE | `/api/v1/accounts/transfers/{id}/` | 转账详情、撤销转账 |
| GET / POST | `/api/v1/categories/` | 分类列表、新增自定义分类 |
| GET / PUT / DELETE | `/api/v1/categories/{id}/` | 分类详情、修改、逻辑删除 |
| GET / POST | `/api/v1/transactions/` | 账单列表、新增账单 |
| GET / PUT / DELETE | `/api/v1/transactions/{id}/` | 账单详情、修改、逻辑删除 |
| GET | `/api/v1/dashboard/summary/` | 首页资产、本月收支、最近账单等汇总 |
| GET | `/api/v1/transactions/summary/` | 指定日期范围收入、支出、结余汇总 |
| GET | `/api/v1/transactions/trend/` | 按日收支趋势 |
| GET | `/api/v1/transactions/monthly-statistics/` | 月度统计及环比 |
| GET | `/api/v1/transactions/yearly-statistics/` | 指定年份各月统计 |
| GET | `/api/v1/transactions/category-statistics/` | 指定范围分类统计 |

表中{id}应替换为真实资源ID。接口地址以本表为准，原文档中的`/user/profile/`及`/statistics/.../`地址已同步调整。

## 注册

```text
POST /api/v1/auth/register/
```

```json
{
  "username": "test005",
  "email": "test005@example.com",
  "phone": "13800000005",
  "nickname": "",
  "password": "Test@123456",
  "confirm_password": "Test@123456"
}
```

username、email、phone、password、confirm_password均必填。nickname可选，未传、空字符串或纯空白时生成随机昵称；自定义昵称保留。

用户名、邮箱、手机号按现有规则检查重复；邮箱忽略大小写并统一转小写。手机号为11位数字且以1开头。

注册和修改密码共用`AUTH_PASSWORD_VALIDATORS`：最少8位、拒绝常见弱密码、拒绝纯数字密码、拒绝与用户名或邮箱过于相似的密码。没有额外要求必须同时包含大小写、数字和特殊字符。两次密码必须相同，校验失败不创建用户和UserProfile。

## 登录

```text
POST /api/v1/auth/login/
```

用户名登录：

```json
{
  "username": "test005",
  "password": "Test@123456"
}
```

邮箱登录使用相同字段名：

```json
{
  "username": "TEST005@EXAMPLE.COM",
  "password": "Test@123456"
}
```

成功后读取`data.access_token`和`data.refresh_token`。邮箱匹配忽略大小写，账号首尾空格会去除，密码空格不会删除。手机号登录暂未提供。

同名用户名优先；不存在同名用户名时才按邮箱查找。历史邮箱对应多个账号时拒绝邮箱登录，避免登录到错误账号，可继续使用用户名登录。错误账号、错误密码和禁用账号均不能获取Token。

## 账单金额筛选

在Apifox的Params填写查询参数，GET请求无需Body：

```text
GET /api/v1/transactions/?min_amount=10.00&max_amount=100.00&page=1&page_size=20
```

|min_amount / max_amount用法|结果|
|---|---|
|只传min_amount=10.00|金额大于等于10.00|
|只传max_amount=100.00|金额小于等于100.00|
|两者都传|包含上下限的金额区间|
|两者均为20.00|金额等于20.00|
|两者均不传或查询参数留空|不限制金额|

两个参数均使用Decimal，允许0.00~999999999999.99，最多两位小数。负数、非数字、超出精度或min_amount大于max_amount返回400。

可叠加`account_id`、`category_id`、`transaction_type`、`tag_id`、`start_date`、`end_date`、`keyword`、`page`、`page_size`。transaction_type为expense或income，日期格式YYYY-MM-DD。page_size显式传入时范围1~100。

导出和回收站共用相同金额筛选：

```text
GET /api/v1/transactions/export/?min_amount=10.00&max_amount=100.00
GET /api/v1/transactions/recycle-bin/?min_amount=10.00&max_amount=100.00
```

金额筛选不改变排序：正常账单按交易时间倒序，回收站按删除时间倒序，时间相同时按ID倒序；用户只能查询自己的数据。导出不受分页限制。

## 统计日期范围

日汇总使用`/api/v1/transactions/summary/`，将start_date和end_date设为同一天；逐日趋势使用`/api/v1/transactions/trend/`。本周、本季度、自定义范围均通过起止日期查询，无需额外新建统计接口。

```text
GET /api/v1/transactions/summary/?start_date=2026-10-15&end_date=2026-10-15
GET /api/v1/transactions/trend/?start_date=2026-10-01&end_date=2026-10-31
GET /api/v1/transactions/monthly-statistics/?month=2026-10
GET /api/v1/transactions/yearly-statistics/?year=2026
GET /api/v1/transactions/category-statistics/?transaction_type=expense&start_date=2026-10-01&end_date=2026-10-31
```

转账不计入普通收入、支出和结余。金额上下限目前用于账单列表、导出、回收站，不用于这些统计接口。

## 自动化验证

```powershell
.\.venv\Scripts\python.exe manage.py test --settings=config.test_settings
```

测试使用独立内存数据库与缓存，不连接开发MySQL和Redis。新增测试覆盖邮箱登录、账号冲突、禁用账号、弱密码、金额边界、异常参数及筛选用户隔离。
